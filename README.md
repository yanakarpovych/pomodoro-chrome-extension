# Pomodoro Timer Chrome Extension

A Chrome extension that helps users stay focused and manage their tasks using the Pomodoro technique.

## Features

- Start, pause, and reset a Pomodoro timer
- Customize the timer duration
- Add, edit, and delete tasks
- Save tasks and timer settings using Chrome Storage
- Keep the timer running when the popup is closed
- Receive notifications when a Pomodoro session ends

## Technologies

- HTML5
- CSS3
- JavaScript
- Chrome Extensions Manifest V3
- Chrome Storage API
- Chrome Alarms API
- Chrome Notifications API

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/yanakarpovych/pomodoro-chrome-extension.git
   ```

2. Open Google Chrome and navigate to `chrome://extensions/`.

3. Enable **Developer mode**.

4. Click **Load unpacked**.

5. Select the project folder.

6. Click the extension icon to open the Pomodoro Timer.

## Usage

- Click **Start Timer** to begin a Pomodoro session.
- Click **Pause Timer** to pause the countdown.
- Click **Reset Timer** to restart the timer.
- Click **Add Task** to create a new task.
- Edit or delete tasks directly in the popup.
- Open the extension's options page to customize the timer duration.
